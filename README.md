# BundleRecommender

**Day 20/100 — 100 Days of Projects**

An experimental product bundle recommendation project.

## Problem

Retail transaction data may reveal products frequently
purchased together. This project explores how transaction
patterns can support transparent product bundle suggestions.

## Planned Approach

1. Dataset discovery and provenance audit
2. Transaction-level cleaning and basket construction
3. Leakage-safe evaluation split
4. Popularity and co-occurrence baselines
5. Association-rule mining and recommendation ranking
6. Offline evaluation
7. FastAPI backend
8. React dashboard

## Status

**Scaffolding stage.**

No dataset, model, evaluation metrics, or deployed application
are claimed at this stage.
